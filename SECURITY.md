# Security Policy

## Supported versions

Security fixes are released for the latest `1.x` version only.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub's ["Report a vulnerability"](https://github.com/vaclavvanik/oauth2-token/security/advisories/new)
button, or by email to **vaclav.vanik@gmail.com**.

Include enough detail to reproduce the issue - affected version, a short description, and a proof of concept
if you have one.

You can expect an acknowledgement within a few days. Once a fix is ready it will be released and the advisory
published, crediting you unless you ask otherwise.
